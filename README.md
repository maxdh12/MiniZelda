# ⚔️ Mini Zelda

Um jogo de aventura 2D inspirado na franquia The Legend of Zelda, desenvolvido em Python utilizando a biblioteca Pygame.

O projeto foi criado como prática de desenvolvimento de jogos, explorando conceitos de programação, movimentação, colisões, animações e sistemas de combate.

## 🎮 Sobre o jogo

Explore diferentes cenários, enfrente inimigos e tente derrotar o monstro que habita o acampamento!

### ✨ Funcionalidades

- Movimentação do personagem em quatro direções.
- Animações de movimento.
- Diferentes mapas: casa, vila e acampamento.
- Transição entre cenários com efeito de fade.
- Sistema de colisões.
- Sistema de combate com espada.
- Inimigo com movimentação e perseguição ao jogador.
- Sistema de vida do jogador e do inimigo.
- Animação de morte do inimigo.
- Tela de Game Over.
- Tela de vitória com opção de reiniciar.
- Editor de colisões integrado.

## 🕹️ Controles

| Tecla | Ação |
|---|---|
| W / ↑ | Movimentar para cima |
| S / ↓ | Movimentar para baixo |
| A / ← | Movimentar para esquerda |
| D / → | Movimentar para direita |
| Espaço | Atacar com a espada |
| F11 | Alternar tela cheia |
| F2 | Ativar/desativar editor de colisões |
| F5 | Salvar colisões |
| Botão direito do mouse | Remover colisão no editor |
| R | Reiniciar após Game Over ou vitória |

## 🚀 Como executar

### 1. Pré-requisitos

Instale o Python e o Pygame:

```bash
python -m pip install pygame
```

### 2. Baixar o projeto

```bash
git clone https://github.com/maxdh12/MiniZelda.git
```

### 3. Entrar na pasta

```bash
cd MiniZelda
```

### 4. Executar o jogo

```bash
python main.py
```
